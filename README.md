# 修改 B671 无线名称与密码 · 操作教程

华为 OptiXstar B671-1E3W（GPON ONU / FTTR 边缘 AP）的无线名称与密码修改全流程。

设备的网页管理面被配置向导锁死，「完成」按钮点下去没有响应，配置页又被 403 挡回。本教程绕过页面，直接调设备自己的 HTTP 接口完成修改，并说明改完为什么可能被回同步。

## 教程结构

1. 适用范围与设备身份
2. 现象：点完「完成」为什么没反应
3. 认设备：边缘 AP 不是路由器
4. 五步流程：取会话 → 读现值 → 分频段提交 → 回读核对 → 收尾
5. 登录链路与三个易忽略点
6. 三个参数形态坑（参数名、字段大小写、双频合提）
7. 错误码 `0x1` 的两种含义与判断顺序
8. 三种落地方式
9. 重启后配置是否保持、何时会被主网关覆盖
10. 验收清单
